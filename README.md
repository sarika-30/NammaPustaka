Project Title :- Namma-Pustaka 
What it is: An Android app that replaces traditional paper-based library systems for schools and small libraries.
Namma Pustaka is an Android based smart library Assistant Application developed for school and small libraries.
The app helps students and teachers manage books digitally in a simple and organized way.
**Key features***:Digital book catalog - Students/teachers can view all available books in the library.
QR code borrowing - Scan a book's QR code to borrow it instantly instead of writing in a register.
Library management - Tracks which books are borrowed, by whom, and due dates.
**Tech stack-** Android native - app folder with Kotlin/Java code.
Gradle - build.gradle.kts, settings.gradle.kts for dependencies/building
